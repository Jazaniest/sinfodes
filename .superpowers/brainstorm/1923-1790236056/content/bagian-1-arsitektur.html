Tools
Yang dipasang, dan alasannya
KebutuhanToolAlasan
Navigasi halamanTanStack RouterFilter tabel ikut tersimpan di URL, jadi hasil filter bisa dibagikan atau di-bookmark.
Pengambilan dataTanStack QueryCache, tampilan loading, dan percobaan ulang saat gagal ditangani rapi.
API tiruanMSWFrontend memanggil HTTP sungguhan; saat backend siap, MSW tinggal dimatikan.
TabelTanStack Table + VirtualSortir, filter, dan pengaturan kolom; tetap lancar untuk ribuan baris.
FormulirReact Hook Form + ZodAturan validasinya sama dengan skema API.
Komponen dasarReact Aria ComponentsAksesibel dan paham format tanggal Indonesia. Tidak punya gaya bawaan, jadi tidak terlihat seperti template.
StylingTailwind CSS v4Dikunci hanya boleh memakai warna, font, dan jarak dari Register.
GrafikRechartsPiramida penduduk dan realisasi APBDes.
PetaMapLibre + OpenFreeMapGratis tanpa API key, gayanya bisa disamakan dengan tema kertas, dan hanya dimuat di halaman peta.
IkonPhosphorDipakai seperlunya; label teks tetap yang utama.
FontIBM Plex (Fontsource)Disimpan di aplikasi sendiri, tidak bergantung pada Google Fonts.
PengujianVitest + Testing LibraryAturan NIK, nomor surat, dan kontrak API diuji otomatis.
